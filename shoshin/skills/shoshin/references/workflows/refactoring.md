# 重构

固定当前行为：复用有效测试或保存有代表性的输入输出，类型检查单独不能证明行为等价。明确目标结构与用户批准范围，保留现有缺陷的事实，不把修复夹入行为保持任务。

## 调用者迁移

在已授权的内部 API 整体迁移中，查实际调用者、序列化名称、动态注册、配置及文档引用，逐批迁移并验证后删除已无调用的旧接口。外部兼容契约未经决定不能删除，不为猜测的消费者无限保留旧路径。

只清理范围内已确认冗余；小步修改，每步保持行为检查通过。批量机械变化先比较直接编辑和脚本，详细判断通过 figure-it-out 仅读 references/execution-methods.md 的工具选择节。新增结构是否降低实际理解和协调负担，是保留依据；不是 diff 是否更小。

交付结构变化与前后等价证据，基线缺失时明确限度。不得擅自 rebase、建分支或改变外部接口。
