# 项目业务术语

## 语境与范围

本表约定本项目中付款企业与实际操作者的称谓，不定义尚未确认的订单规则或跨企业用户关系。

## Language

### Customer

付款的企业。一个 Customer 可以有多个 User。

_Avoid_: Account（不得用它混称 Customer 和 User）。

### User

实际登录并操作系统的个人。

_Avoid_: Account（不得用它混称 User 和 Customer）。
